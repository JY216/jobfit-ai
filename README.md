# JobFit AI

채용공고와 지원자의 기술·프로젝트 경험을 분석하여  
직무 적합도를 제공하는 개인 프로젝트입니다.

> 🚧 **현재 개발 진행 중인 프로젝트입니다.**  
> 채용공고 분석 및 직무 적합도 분석 기능을 FastAPI 기반으로 구현했으며,  
> 웹 서비스 확장을 위한 프론트엔드 및 백엔드 개발을 진행하고 있습니다.

---

## 프로젝트 소개

취업 준비 과정에서 여러 채용공고를 확인할 때마다  
보유한 기술과 프로젝트 경험이 공고의 요구사항에 얼마나 부합하는지  
반복적으로 판단해야 하는 불편함에서 시작한 프로젝트입니다.

채용공고에서 필수·우대 기술과 주요 요구사항을 추출하고,  
지원자의 기술 및 프로젝트 경험과 비교하여  
직무 적합도를 분석하는 것을 목표로 합니다.

---

## 주요 기능

### 채용공고 분석
- 채용공고 내용 파싱
- 필수 기술 / 우대 기술 분리
- 중복 기술 및 표현 정리
- 분석 결과 구조화

### 직무 적합도 분석
- 지원자 보유 기술과 요구 기술 비교
- 필수 / 우대 기술 매칭률 계산
- 프로젝트 및 경험 적합도 분석
- 분석 결과 및 적합도 점수 제공

## API

### `POST /parse-job`

채용공고 내용을 분석하여 필수 기술, 우대 기술 등의 정보를 구조화합니다.

### `POST /analyze-job`

지원자 프로필과 채용공고를 비교하여  
기술 및 프로젝트 경험의 적합도를 분석합니다.
